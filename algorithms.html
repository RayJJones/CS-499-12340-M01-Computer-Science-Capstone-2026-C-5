Artifact Description

The artifact selected for this enhancement is my Weight Tracker mobile application, originally developed in CS360 Mobile Architecture and Programming. The initial version of the application provided basic functionality for recording daily weight entries and displaying them in a simple list. While functional, the original implementation relied on a singletable SQLite structure, minimal data modeling, and limited algorithmic processing. The artifact lacked architectural rigor, algorithmic depth, and data structure sophistication expected at the capstone level. For Milestone Three, I substantially redesigned and enhanced the artifact to demonstrate competency in algorithms, data structures, and software engineering principles.

Justification for Inclusion in the ePortfolio

This artifact was selected for inclusion in my ePortfolio because it effectively demonstrates my ability to transform an introductorylevel mobile application into a more robust, scalable, and professionally engineered system. The enhancements completed for Milestone Three showcase several core competencies in the Computer Science program, particularly in the areas of algorithmic design, data structure implementation, secure coding, and database engineering.

Several components of the enhanced artifact highlight these skills:

1. Introduction of a Structured Model Layer

I created a dedicated model package containing new classes such as User, Goal, WorkoutEntry, WorkoutHistory, and Recommendation. These classes provide a clear, objectoriented representation of the application’s data. This structured approach improves maintainability, supports relational database operations, and enables more complex algorithmic processing.

2. Relational Database Redesign

The original singletable database was replaced with a unified relational schema implemented in AppDatabaseHelper. The new schema includes multiple tables—Users, Goals, WorkoutHistory, WorkoutEntries, and Recommendations—each with foreign keys, constraints, and indexes. I also implemented new DAOstyle methods such as getAllWorkoutHistory() and deleteWorkoutHistory(). This redesign demonstrates my ability to apply database engineering principles and support more advanced data operations.

3. Secure Password Handling

To strengthen the security posture of the application, I implemented SHA256 hashing for user passwords through a new PasswordUtils class. This enhancement reflects a securityfocused mindset and aligns with industry best practices for protecting user credentials.

4. RecommendationEngine Algorithm

The most significant enhancement in the algorithms and data structures category is the implementation of the RecommendationEngine. This component analyzes user behavior and progress using weighted scoring, linear scans (O(n)), and sorting (O(n log n)). It evaluates consistency, activity level, and weight trends to generate ranked recommendations. This algorithm demonstrates my ability to design and implement meaningful computational logic that produces actionable insights for users.

5. Enhanced WeightAdapter with Sorting and Steps Tracking

I upgraded the RecyclerView adapter to sort entries by date using a comparator (O(n log n)), display steps alongside weight, and integrate the new WorkoutHistory model. This enhancement improves the user interface while demonstrating practical application of algorithms within UI components.

6. Updated WeightHistoryActivity

The activity was refactored to load WorkoutHistory objects instead of the legacy WeightEntry class. It now interacts with the updated database helper, supports steps tracking, and uses improved edit/delete callbacks. This change ensures consistency across the application’s architecture.

7. UI Improvements

I updated row_weight.xml to include a new tvSteps field and replaced hardcoded strings with resource references. These changes improve accessibility, maintainability, and adherence to Android development standards.

Collectively, these enhancements justify the artifact’s inclusion in my ePortfolio as a demonstration of my ability to design, implement, and refine computing solutions using algorithmic principles and structured data management.

Reflection on the Enhancement Process

Enhancing this artifact provided valuable insight into the importance of clean architecture, modular design, and algorithmic thinking. Transitioning from a singletable database to a relational schema required careful planning and a deeper understanding of data relationships. Implementing the recommendation algorithm challenged me to think critically about data flow, computational efficiency, and how to generate meaningful insights for users.

One of the primary challenges involved ensuring consistency across the application after transitioning to the new WorkoutHistory model. Updating the adapter, activity, and database required coordinated changes and thorough testing. Another challenge was integrating sorting and filtering logic without disrupting existing functionality. These experiences strengthened my understanding of Android development, algorithms, and data structures, and prepared me for more advanced engineering tasks.

Overall, the enhancements completed for Milestone Three significantly improved the artifact’s quality, functionality, and maintainability. The redesigned application now reflects professional software engineering standards and demonstrates my readiness to contribute effectively to the field of computer science.
