For Milestone Three, I chose to enhance my Weight Tracker App, which I originally created in CS-360. It’s an Android application that lets users enter their weight, set goals, and track their progress over time. When I first built it, the app worked, but it was pretty simple and lacked validation and helpful feedback. Because of that, I felt it was a great project to improve and include in my ePortfolio. It shows the skills I’ve learned throughout the computer science program, and it’s also a practical app that people could actually use.

I chose this artifact because it highlights several important areas of software engineering, like working with Activities, XML layouts, SQLite databases, and SharedPreferences. It also shows my ability to revisit older code, understand what’s missing, and make meaningful improvements. This is something developers do all the time, so I wanted to show that I can evaluate and enhance an existing project instead of only building new ones from scratch. The enhancements I made make the app feel more polished and professional, which is exactly what I want to show in my ePortfolio.

For this milestone, I improved multiple parts of the app. On the dashboard, I added a new Personalized Recommendations section that gives users workout and diet suggestions based on their selected goal type. I also improved the progress bar and added a message that appears when users reach their goal. On the goal-setting screen, I added radio buttons so users can choose whether they want to lose weight, gain muscle, or maintain their current weight. This connects directly to the dashboard recommendations. I also improved validation and accessibility on this screen.

On the Add Weight screen, I added a date picker, so users don’t have to type dates manually. I also added stronger validation for weight input and date format. On the Settings screen, I improved the username and password update process by adding rules like minimum length and requiring letters and numbers in the password. I also added checks to ensure a user is logged in before updating anything. Across all XML files, I removed hardcoded strings, improved accessibility, added comments showing where I made enhancements, and cleaned up spacing and structure.

These enhancements helped me meet several course outcomes, especially in software engineering and design. I improved the app's structure, added new features, and made the code cleaner and easier to understand. I also made progress toward the security outcome by improving password rules and preparing the code for hashing later. I also made progress toward algorithmic thinking by setting up the goal type system, which will support a more advanced recommendation algorithm in a future milestone.

Working on this enhancement taught me a lot about improving existing code. I learned how important it is to write clean, readable layouts and avoid hardcoded strings. I also learned how much better an app feels when it gives clear feedback and prevents bad input. One challenge I faced was making sure all the XML IDs matched the Java code. Another challenge was improving validation without making the app annoying to use. I also had to think more about user experience, like adding the date picker and making sure the app responds in helpful ways. Overall, this milestone helped me understand how to take a basic app and turn it into something more polished and professional. It also prepared me for the next milestones, where I’ll be adding more advanced algorithms and a stronger database design.
